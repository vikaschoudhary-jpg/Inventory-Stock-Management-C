# Inventory and Stock Management System in C

A console-based Inventory and Stock Management System developed using C programming language as a Data Structures and Algorithms (DSA) college project.

## Features

- Add new inventory items
- Update existing item details
- Delete discontinued items
- Stock In (purchase management)
- Stock Out (sales management)
- Search products by code or name
- Low-stock alerts
- Display all inventory records
- Sort products using Bubble Sort, Selection Sort and Insertion Sort
- Generate inventory reports
- Save and load records using file handling

## Technologies Used

- C Programming Language
- Structures and Arrays
- File Handling
- Linear Search
- Bubble Sort
- Selection Sort
- Insertion Sort

## How to Run

Compile the program:

```bash
gcc inventory.c -o inventory.exe
```

Run on Windows:

```bash
.\inventory.exe
```

## DSA Concepts

| Concept | Implementation |
|---|---|
| Array of Structures | Inventory storage |
| Linear Search | Product searching |
| Bubble Sort | Sorting by price |
| Selection Sort | Sorting by quantity |
| Insertion Sort | Sorting by name |
| File Handling | Persistent data storage |
